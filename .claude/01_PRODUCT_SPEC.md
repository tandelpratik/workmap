# Product Specification

## Working product name

WorkMap

## Tagline

See where the work is.

## Positioning

An Australian job-market intelligence platform that connects live/permitted job discovery with labour-market demand, geography, skills and trends.

## Core promise

Help users answer:
1. What jobs are available?
2. Where are opportunities concentrated?
3. Which occupations are in demand?
4. Which skills are requested?
5. How is demand changing?

## Primary journey

Occupation/search
→ Market overview
→ Australian heatmap
→ State/region drilldown
→ Actual job listings
→ Skills
→ Salary
→ Trends

## Primary navigation

Jobs
Market
Skills
Locations
Trends

## MVP capabilities

### Jobs
- keyword search
- occupation search
- state/city/region filtering
- salary filtering
- employment type
- remote/hybrid/onsite
- freshness
- source
- application destination

### Market
- national demand
- state demand
- regional demand
- occupation profiles
- historical trend
- change/ranking

### Geography
- Australia
- states/territories
- SA4/IVI regions where supported
- authoritative boundaries
- drilldown

### Skills
- deterministic extraction first
- occupation × skill matrix
- skill frequency
- skill geography
- skill trend

### Salary
- reported salary
- median/average when statistically reasonable
- sample size
- explicit missingness

## Non-goals for initial release

- employer portal
- payments
- subscription billing
- real-time streaming
- candidate marketplace
- automated application submission
- guaranteed visa sponsorship claims
- LLM dependency for core features
- unauthorized scraping
