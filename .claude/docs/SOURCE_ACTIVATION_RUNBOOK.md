# Source Activation Runbook

## Adzuna

1. Obtain authorized onboarding/access.
2. Review current terms.
3. Verify commercial/display/redistribution rights.
4. Store credentials in secret environment configuration.
5. Enable the adapter through configuration.
6. Run contract and data-quality tests.
7. Run controlled ingestion.
8. Verify provenance, links and duplicate handling.
9. Enable production traffic gradually.

## If Adzuna remains unavailable

Continue the product with JSA market intelligence and keep individual job search unavailable rather than fabricating jobs.

## Alternative source

Any alternative provider must implement the generic source adapter, pass compliance, provenance, quality and safety gates, and be explicitly enabled.
