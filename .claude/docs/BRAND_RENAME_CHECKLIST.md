# Brand Rename Checklist

WorkMap is a temporary product name.

When renaming:

[ ] Update brand configuration
[ ] Replace logo
[ ] Replace favicon
[ ] Update metadata
[ ] Update public copy
[ ] Update documentation
[ ] Update social assets
[ ] Update legal/public product name where applicable
[ ] Update domain configuration when ready
[ ] Run full regression tests

Do NOT rename:
- Job
- Company
- User
- Geography
- source adapters
- API semantics
- database entities
- analytics concepts

The brand is a presentation/configuration concern.
