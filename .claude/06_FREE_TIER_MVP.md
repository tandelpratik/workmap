# Free-Tier MVP

## Product status

This is a real product MVP operated at low cost, not a tutorial.

## Objectives

Prove:
- data quality
- user value
- heatmap UX
- job search
- market intelligence
- source pipeline
- commercial feasibility

## Initial stack

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Zod
- MapLibre
- Recharts
- Adzuna API
- JSA data

## Cost controls

- cache permitted API responses
- scheduled imports
- controlled Adzuna queries
- store processed JSA data
- avoid repeated downloads
- PostgreSQL-first search
- small map payloads
- no paid AI dependency

## Deferred

- Redis
- Elasticsearch/OpenSearch
- Kubernetes
- paid queues
- large email system
- billing
- employer portal
- advanced AI matching

## Commercial mindset

Do not sacrifice:
- source compliance
- security
- data provenance
- accessibility
- maintainability

just because the deployment is free-tier.
