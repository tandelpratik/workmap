# WorkMap Design System

## Strategic direction

Editorial data journalism + modern cartography + Australian employment intelligence.

The visual reference should feel closer to:
- an atlas
- a newspaper data section
- a research publication
- a modern statistical bureau

than:
- AI startup
- HR SaaS
- generic recruitment dashboard

## Typography

Preferred:
- IBM Plex Sans for UI/data
- Source Serif 4 for editorial/display

## Base visual language

Use:
- paper/off-white surfaces
- near-black ink
- warm neutral borders
- restrained data colours
- thin rules
- whitespace
- strong alignment
- typography-led hierarchy

## Heatmap palette

Use a sequential scale appropriate to quantitative data.

Avoid:
- rainbow scales
- decorative gradients
- neon
- purple/blue AI gradients

## Components

Do not turn every element into a card.

Use:
- editorial rows
- rules
- labels
- compact control strips
- map legends
- tables
- side information panels
- restrained panels where they communicate grouping

## Homepage

The map should appear early.

Suggested structure:
- concise editorial introduction
- occupation/search input
- market shortcuts
- primary map/market visualization
- current job openings
- market notes

## Job listing

Prefer rows over oversized cards.

Show:
- title
- company
- location
- employment
- salary
- key skills
- freshness
- source
- application action

## Heatmap

Map is a primary interface.

Do not place it inside multiple nested cards.

Selection should persist.

Provide accessible table alternative.

## Copy

Prefer:
- Market note
- Job advertisements
- Reference period
- Source
- Methodology
- Explore demand
- Compare locations

Avoid:
- AI insights
- magic match
- career copilot
- supercharge your career

## Responsive

At mobile width:
- controls stack
- map remains usable
- details move below/alongside
- table can scroll horizontally locally
- no page-level horizontal overflow

## Accessibility

- keyboard navigation
- visible focus
- semantic headings
- labels
- accessible tables
- colour-independent interpretation
- readable legends
